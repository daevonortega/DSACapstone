IT Help Desk Ticketing System

Project Description

A console-based Java application designed to manage IT help desk tickets using sorting algorithms and queue operations.

Features

* Add new support tickets
* Process tickets using FIFO (First In, First Out)
* View the next ticket
* Display all tickets
* Bubble Sort by ticket number
* Selection Sort by requester name
* Search tickets by ticket number

Technologies Used

* Java
* IntelliJ IDEA
* Git and GitHub

Data Structures

* ArrayList
* Queue (LinkedList)

Sorting Algorithms

* Bubble Sort
* Selection Sort

How to Run

1. Open the project in IntelliJ IDEA.
2. Open Main.java.
3. Run the main method.
4. Follow the console menu.
